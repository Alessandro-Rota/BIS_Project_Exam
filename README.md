# BIS_Project_Exam
This is a public web page for the 30-11-26 BIS Exam on Brazilian health dataset.

Starting from a Brazilian hospital dataset, we want to observe some aspects on how is the flow working and achieve some knowledge about it, especially the objectives we’ll try to accomplish are:
-  efficient patient flow: in order to minimize the waiting time for patients and try to          improve the overall experience of the hospital,
-  analyze process: find structural inefficiencies and assess conformance,
-  propose improvements
